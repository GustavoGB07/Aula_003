Etapas para a publicação de uma página HTML

  1. Crie uma conta no GitHub (se não tiver).
  2. Crie um novo repositório público e dê um nome a ele.
  3. Faça o upload dos seus arquivos (incluindo o index.html) para esse repositório.
  4. Acesse as configurações (Settings) do repositório.
  5. Vá até a aba "Pages" no menu lateral esquerdo.
  6. Selecione a branch principal (geralmente main ou master) em Build and deployment e clique em Save.
  7. Aguarde alguns minutos e o GitHub fornecerá o link público do seu site (ex: seu-usuario.github.io/nome-do-repositorio).

A sequência deve ser obedecida para estabelecer o resultado do objetivo final, por exemplo, o passo B não deve vir primeiro que o passo A, pois o passo B necessita de uma conta criada e o passo A é o passo de criação da conta

Como reservar livros

  1. Cada passo é importante e deve ser seguido
  2. Faça os passos em sequência A-Z
  3. Um passo posterior só pode ser feito se o passo q antecede ele tenha sido finalizado
